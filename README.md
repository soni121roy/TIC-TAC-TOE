# ❌⭕ TIC TAC TOE

Simple and responsive Tic Tac Toe game.

**Live Demo:** https://soni121roy.github.io/TIC-TAC-TOE/

## Features
- 2 Player Mode (X vs O)
- Win detection
- Reset Game
- Responsive design

## Tech Stack
- HTML5
- CSS3 (Grid)
- JavaScript (Vanilla)

## How to Play
1. Player X starts
2. Click on any box
3. First to make 3 in a row wins
